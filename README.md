# primal-dual-sat

Code accompanying the submission *From GNNs to Continuous Relaxations and Back: A Primal-Dual View of Neural SAT Solving* (under review).

This repository will hold the explicit primal-dual operator (PDO and PDO-X), the simplified bipartite GNN with its test-time and training fixes, the evaluation protocol, and the scripts that produce the tables and figures of the paper. The code is being prepared for release and will be uploaded here during the review period.
